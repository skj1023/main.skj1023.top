# 国产信创与信创操作系统研究

> 资料截止：2026-07-30。本文用于建立可复核的技术与采购认知框架，不把“国产”“适配认证”“安全可靠”混同为同一概念。

## 一、结论先行

1. **信创不是一套操作系统，也不是单一 CPU 替代项目**，而是一条覆盖芯片/整机、基础软件、应用软件、网络安全、运维服务和迁移交付的产业链。
2. **操作系统是生态枢纽，不是全部价值**。真正决定替换难度的通常是应用兼容、驱动/外设、数据库与中间件、身份/安全体系、集中运维和人员能力。
3. 国产 OS 应按场景看：桌面办公、服务器、云原生、嵌入式/工业、实时/安全增强，不宜把 UOS、银河麒麟、openEuler、Anolis OS、麒麟信安等当作同类单品直接排名。
4. **商业发行版与开源社区发行版的责任边界不同**：统信 UOS、银河麒麟、麒麟信安更偏商业支持和行业交付；openEuler、openKylin、Anolis OS强调社区协作、上游开放和衍生发行。
5. “兼容认证”通常说明某版本组合通过了特定测试，不等于所有版本、驱动、插件和业务流程都能运行；采购必须以目标应用清单和现场验收为准。
6. 最稳妥的迁移方法是“清单化、分层、双轨、灰度、可回退”，先做应用与外设盘点，再做 PoC，不建议先买 OS、后找兼容性。

## 二、信创产业链地图

| 层 | 典型内容 | 采购关注点 |
|---|---|---|
| 芯片与板卡 | 龙芯、飞腾、鲲鹏、海光、兆芯、申威；AI/安全加速 | 指令集、驱动、性能功耗、供货、固件、编译器 |
| 整机与基础设施 | 桌面机、服务器、工作站、存储、网络设备 | BOM 可追溯、备件、远程管理、认证组合 |
| 操作系统 | UOS、银河麒麟、麒麟信安、openEuler、Anolis OS、openKylin 等 | 生命周期、补丁、兼容范围、商业支持、工具链 |
| 数据库 | 关系型、分布式、分析型、时序/国产替代 | SQL/存储过程兼容、事务、驱动、备份、迁移工具 |
| 中间件 | 应用服务器、消息、缓存、ESB、容器平台 | Java/.NET 运行时、集群、监控、许可证 |

| 安全 | 身份、密码、终端、主机、边界、审计、漏洞管理 | 等保/密评边界、国密、集中策略、响应时间 |
| 服务交付 | 适配、迁移、培训、运维、备件、驻场 | SLA、回退方案、知识转移、总拥有成本 |

## 三、操作系统分层与厂商路线

### 1. 统信 UOS / 统信软件

- **定位**：商业桌面、服务器、云原生和智能终端操作系统，强调同源异构、多 CPU 架构和政企规模化支持。
- **公开路线**：统信官网目前展示桌面操作系统 V25 专业版、服务器 OS、云原生 OS、智能终端 OS，并提供适配指南、生态适配申请、适配清单和 UHQL 硬件兼容适配计划。
- **优势**：桌面产品体验、商业支持、应用商店与生态认证、整机厂合作、迁移服务较完整。
- **短板/风险**：跨架构应用、专有插件、复杂外设和深度行业软件仍需逐项验证；版本生命周期与订阅/服务费用需写入合同。
- **适合**：政企桌面、办公终端、统一终端管理，以及需要商业化服务的服务器迁移项目。

### 2. 银河麒麟 / 麒麟软件

- **定位**：商业桌面、服务器、智算、工业和万物智联操作系统，覆盖党政、金融、能源、通信、交通、教育、医疗和企业场景。
- **公开路线**：麒麟软件官网列出服务器 OS、桌面 OS、智算 OS、工业 OS、万物智联 OS、openKylin，并提供生态合作、适配认证和兼容适配清单。
- **优势**：政企和行业项目经验、服务器产品、适配认证体系和服务网络较成熟；行业解决方案覆盖广。
- **短板/风险**：同一品牌下产品线和版本较多，不能只凭“麒麟”名称判断兼容性；旧应用、打印/扫描、控件和专有安全模块仍是迁移高频风险。
- **适合**：党政和行业桌面/服务器、对认证和商业服务有明确要求的项目。

### 3. openEuler

- **定位**：面向数字基础设施的开源操作系统社区，覆盖服务器、云、边缘、嵌入式和 AI 基础设施。
- **公开路线**：官网提供技术白皮书、安全中心、迁移专区、开发工具链、SIG 和发行厂商体系；页面显示其强调多样性设备、全场景应用和完整开发工具链。
- **优势**：开放社区、服务器/云原生基础设施能力、上游协作、可由多个商业 OSV 提供支持；适合构建自主发行版和云平台。
- **短板/风险**：社区版本本身不等于完整商业支持；企业需明确 OSV、补丁责任、认证版本、长期维护和问题升级路径。
- **适合**：服务器、云原生、容器、边缘和需要深度定制的基础设施。

### 4. Anolis OS / 龙蜥操作系统

- **定位**：面向服务器、云计算和数字基础设施的开源社区及发行生态。
- **公开路线**：以社区协作、服务器发行版、云上兼容和企业级支持为主要方向。
- **优势**：云计算场景、开源协同、CentOS 迁移承接和服务器生态价值较明显。
- **短板/风险**：社区、商业发行版和云厂商支持边界需单独核实；不要将社区影响力直接等同于本地桌面软件兼容性。
- **适合**：服务器、云平台、容器与企业级基础设施替换。

### 5. openKylin

- **定位**：由开放原子开源基金会孵化及运营的开源操作系统项目。
- **公开路线**：官网提供下载、社区、学习、开发、支持、兼容适配、衍生发行版和 SIG 体系。
- **优势**：开源协作、开发者参与、社区透明度和衍生发行能力。
- **短板/风险**：企业采购需确认商业支持方、补丁 SLA、认证组合与行业应用责任，不应把社区项目直接当成商业服务合同主体。
- **适合**：开发者、教育、桌面探索、衍生发行和开源生态建设。

### 6. 麒麟信安

- **定位**：操作系统、云计算和数据安全产品供应商，覆盖服务器、桌面、嵌入式、工业 OS、云桌面、云平台和安全产品。
- **公开路线**：官网列出操作系统、云计算、信息安全产品，并展示党政、能源、金融、教育等方案，以及兼容适配清单和 CentOS 替换/加固方案。
- **优势**：安全增强、云桌面、虚拟化、行业场景和安全产品协同明显。
- **短板/风险**：更适合特定行业和安全场景；必须核对目标外设、应用和硬件组合的版本支持。
- **适合**：安全云桌面、能源/金融/政务、服务器和嵌入式/工业场景。

## 四、CPU、架构与 OS 的关系

| 架构/平台 | 常见组合 | 迁移含义 |
|---|---|---|
| x86 | 海光、兆芯及传统生态 | 二进制和软件资产承接相对容易，但仍需检查指令集、驱动和授权 |
| ARM64 | 鲲鹏、飞腾等 | 服务器和云原生适配较活跃；闭源 x86 二进制、商业插件是风险点 |
| LoongArch | 龙芯 | 需要关注编译器、基础库、应用原生构建和硬件外设 |
| 申威等专用架构 | 特定行业/高安全/高性能场景 | 项目化交付和专用软件适配要求高 |
| RISC-V | 嵌入式、教育、边缘和部分专用场景 | 生态成长快但商业桌面/大型行业软件成熟度需核验 |

**核心原则**：操作系统兼容不等于应用兼容。必须同时验证 ISA、ABI、编译器、运行时、驱动、浏览器内核、数据库客户端、打印/扫描和安全控件。

## 五、迁移方法：从“换系统”转为“换栈管理”

1. **建立资产清单**：终端、服务器、CPU 架构、系统版本、应用、浏览器插件、外设、字体、打印模板、证书、脚本和数据接口。
2. **应用分级**：A 类可直接迁移；B 类需要厂商升级或适配；C 类依赖闭源驱动/插件；D 类暂不具备替换条件。
3. **做组合 PoC**：固定“CPU/整机 + OS + 浏览器 + 办公 + 数据库 + 外设 + 安全组件”组合，禁止只测单一 OS。
4. **建立验收基线**：启动、登录、打印、扫描、视频会议、电子签章、文件互转、脚本、备份、补丁、故障恢复和性能。
5. **灰度双轨**：先选低风险部门或非核心业务，保留原系统回退能力和数据双向校验。
6. **规模化交付**：统一镜像、软件仓库、补丁策略、终端策略、监控、资产和服务台。
7. **持续运营**：把适配清单、漏洞响应、版本升级、供应商 SLA 和人员培训纳入年度预算。

## 六、典型场景决策

| 场景 | 优先关注 | 推荐研究路径 |
|---|---|---|
| 政企桌面办公 | 文档、浏览器、打印、签章、会议 | UOS/银河麒麟商业发行版 + 应用兼容清单 |
| 数据中心服务器 | 稳定性、容器、数据库、监控、补丁 | openEuler/Anolis OS/商业服务器 OS + OSV 支持 |
| 金融/能源 | 高可用、安全、密码、审计、灾备 | 商业发行版 + 安全增强 + 厂商联合验收 |
| 云桌面 | 集中运维、协议、外设重定向、成本 | 麒麟信安/UOS/麒麟服务器生态方案对比 |
| 工业/嵌入式 | 实时性、驱动、生命周期、现场总线 | 工业 OS/嵌入式发行版 + 硬件联合适配 |
| CentOS 替换 | 仓库、依赖、内核模块、容器、运维脚本 | openEuler/Anolis OS/商业服务器版 PoC |

## 七、容易被忽略的风险

- 把“国产 CPU + 国产 OS”误认为全栈自主；浏览器、数据库、办公套件、固件和安全模块可能仍是外部依赖。
- 用“兼容认证数量”代替真实业务验收；认证通常有版本、架构、配置和测试边界。
- 只测功能，不测打印、扫描、UKey、电子签章、视频会议、字体、宏、脚本和批量运维。
- 只看采购价格，不算迁移、培训、应用改造、备件、驻场、许可证和回退成本。
- 只选桌面 OS，却没有配套服务器、数据库、中间件、身份和安全策略。
- 只看社区活跃度，不确认商业支持、补丁窗口和事故责任人。

### 证据限制

厂商官网中的生态伙伴数、适配数量、案例数量和“自主可控”等表述具有厂商自身统计边界。本文只将其作为产品定位和能力信号，不当作统一市场份额、全行业覆盖率或第三方性能结论。
