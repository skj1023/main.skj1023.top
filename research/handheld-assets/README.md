# 掌机游戏图片素材

本目录收录页面中 12 款 GBA / PSP 游戏的真实封面、实机截图与标题画面缩略图，来源为 [libretro-thumbnails](https://github.com/libretro-thumbnails/libretro-thumbnails) 对应平台仓库的 `Named_Boxarts`、`Named_Snaps`、`Named_Titles` 目录。

- 图片仅用于游戏推荐页面的识别、展示与信息参考，不提供 ROM、镜像或下载服务。
- 游戏名称、角色、美术及相关图片版权归各自的著作权人和发行商所有；本项目不主张拥有这些权利。
- `ace-attorney` 使用原始 GBA 日版《逆转裁判》（`Gyakuten Saiban`）素材，不是 DS 版追加章节《Rise from the Ashes》。
- `type-0` 使用 PSP 原版日版《Final Fantasy Reishiki》（零式）素材，不是 HD 重制版。
- 各文件的完整原始 URL、平台、用途标签记录在 `manifest.json` 中。
